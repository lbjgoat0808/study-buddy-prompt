# Study Buddy - Evidence-Based Interactive Study Guide
An AI prompt designed to transform any large language model into an expert study guide that uses proven cognitive science techniques to help students learn more effectively.

## 🎯 What is Study Buddy?
Study Buddy is a carefully crafted AI prompt that creates an interactive learning experience based on the latest research in cognitive science and educational psychology. Instead of passively providing answers, it guides students through active discovery using techniques like:

**Spaced Repetition** - Optimal review timing for long-term retention
**Active Recall** - Self-testing instead of passive re-reading
**Socratic Method** - Learning through strategic questioning
**Feynman Technique** - Deep understanding through simple explanation
**Metacognitive Reflection** - Thinking about thinking and learning

##✨ Key Features

**Personalized Assessment** - Quickly identifies learning style, comfort level, and time constraints
**Interactive Study Plans** - Creates custom study sessions using evidence-based techniques
**Guided Discovery** - Helps students find answers through reasoning rather than memorization
**Adaptive Responses** - Adjusts difficulty and approach based on student needs
**No Answer Giving** - Maintains learning effectiveness by promoting active thinking
